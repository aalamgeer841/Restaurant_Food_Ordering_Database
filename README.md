# Restaurant Food Ordering Database

## Project Description
This project is a Restaurant / Food Ordering Database Management System developed using MySQL.

The database manages restaurant menu items, tables, staff, orders, order items, and billing information.

## Technologies Used
- MySQL
- SQL

## Database Tables
1. Staff
2. Restaurant Tables
3. Menu
4. Orders
5. Order Items
6. Billing

## SQL Concepts Used
- Primary Key
- Foreign Key
- Constraints
- JOIN
- GROUP BY
- HAVING
- Subquery
- View
- Trigger
- Aggregate Functions

## Main Features
- Manage restaurant staff
- Manage restaurant tables
- Manage menu items
- Manage customer orders
- Manage order items
- Manage billing and payments
- Generate useful reports

## Project File
`Restaurant_Food_Ordering_Database.sql`

## Conclusion
This project demonstrates how MySQL can be used to efficiently manage restaurant operations, orders, menu items, staff, tables, and billing.
